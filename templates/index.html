📊 Ajuste sua planilha para importar no BotConversa

Envie sua planilha (.xlsx, .xls ou .ods) e deixe nosso sistema organizá-la no padrão certo de importação.

Padrões Aceitos

Tipo 1
nome, telefone, etiquetas

Se você tiver uma planilha com esse padrão, basta importar ela para que nosso script separe automaticamente nome e sobrenome e ajuste as outras colunas com telefone e etiquetas.

Tipo 2
primeiro nome, sobrenome, telefone, etiquetas

Este é o padrão aceito para importação. Você pode usar esse sistema para limpar colunas e linhas vazias antes de processar.

Detalhes importantes

  • Os telefones brasileiros precisam ter DDI 55.
  • A planilha de saída será sempre no padrão do Tipo 2.
  • Para fazer importação com campos personalizados, consulte esse vídeo aqui.
